# AlwaysON

«Всегда включённые» часы для Android — заменяют/дополняют стандартный *Always On
Display* через **системную экранную заставку** (DreamService).

## Как это работает

На Android нет публичного API, чтобы рисовать изображение **при полностью
выключенном экране** (это делает закрытый AOD производителя). Поэтому используется
штатный механизм — **экранная заставка**: Android сам включает её, когда телефон
простаивает и **заряжается / стоит в доке**, и сам выключает при любом действии
пользователя (касание, перемещение устройства). Это и есть честный
«always-on» на не-rooted устройстве, и из него нельзя «застрять» — система всегда
возвращает управление пользователю.

## Возможности

- Большие цифровые часы, дата и заряд батареи.
- **Абсолютно чёрный фон** (`#000000`) — на OLED-экранах подсветка выключена,
  светятся только цифры (экономия заряда).
- Регулировка **яркости текста** часов (фон всегда остаётся чёрным).
- Переключатели: 12/24-часовой формат, секунды, процент заряда.
- Без интернета и без AndroidX — собирается «из коробки» в Android Studio.
- Интерфейс на русском (с резервом на английском).

## Как собрать и запустить

1. **Android Studio** → `File ▸ Open` → выбрать папку проекта (где лежит
   `settings.gradle.kts`), согласиться на Gradle Sync.
2. Студия сама скачает Gradle 8.6 и SDK (compileSdk 34). При необходимости
   поставьте платформу Android 14 (API 34) через `SDK Manager`.
3. Подключите телефон по USB с включённой отладкой (`Developer options ▸ USB
   debugging`) или выберите эмулятор.
4. Нажмите **Run** ▶ (Shift+F10).

## Как включить заставку

1. Запустите приложение и настройте вид часов (формат, секунды, заряд, яркость).
2. Нажмите **«Открыть настройки заставки»** (или вручную: `Настройки ▸ Дисплей ▸
   Экранная заставка` / `Screen saver`).
3. Включите заставку и выберите **«AlwaysON часы»**.
4. Условие запуска выберите **«Во время зарядки»** (или «В доке и при зарядке»).
5. Поставьте телефон на зарядку — через несколько секунд появятся часы на чёрном
   экране. Любое касание выключает их и возвращает обычный экран.

> Если в списке заставок нет «AlwaysON часов» — убедитесь, что заставка включена,
> а приложение установлено; в редких случаях помогает перезапуск устройства.

## Структура проекта

```
app/src/main/
├─ AndroidManifest.xml            — activity + DreamService-заставка
├─ java/com/aidarbreeze/alwayson/
│  ├─ MainActivity.kt            — экран настроек
│  ├─ Prefs.kt                   — SharedPreferences-хранилище
│  ├─ AodViews.kt                — отрисовка времени/даты/батареи
│  └─ dream/ClockDreamService.kt — заставка (always-on часы)
└─ res/
   ├─ layout/                    — aod_view.xml, activity_main.xml
   ├─ values / values-ru/        — строки (RU основной)
   ├─ mipmap-anydpi-v26/         — адаптивная иконка
   └─ xml/dream_info.xml         — метаданные заставки
```

## Минимальные требования / версии

- `minSdk 26` (Android 8.0+), `targetSdk/compileSdk 34` (Android 14).
- Kotlin 1.9.24, AGP 8.4.2, Gradle 8.6 (скачиваются автоматически).
- Внешних библиотек нет — используется только Android SDK.

## Если Android Studio ругается на Gradle wrapper

Бинарный `gradle/wrapper/gradle-wrapper.jar` не закоммичен (не текст, в этой среде
не создаётся). Обычно студия сама разворачивает Gradle из
`gradle-wrapper.properties`. Если появится `Could not find or load main class
org.gradle.wrapper.GradleWrapperMain` — выполните на машине с Gradle:
`gradle wrapper --gradle-version 8.6` (создаст недостающий jar), либо укажите
локальную Gradle-дистрибуцию в `File ▸ Settings ▸ Build Tools ▸ Gradle`.
