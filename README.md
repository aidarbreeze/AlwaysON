# AlwaysON

StandBy-экран в стиле iPhone для Android: **крупные часы, дата, месяц-календарь**
и **компактный плеер** «сейчас играет», на **чисто чёрном OLED-фоне**, когда
телефон заряжается в горизонтальном положении (на подставке).

> Публичного API рисовать картинку при **полностью выключенном** экране в Android
> нет (это AOD производителя). Поэтому приложение использует ближайшие
> поддерживаемые варианты и отлично работает на телефонах вроде **OnePlus/OxygenOS**,
> где системная «заставка» при зарядке почти не запускается.

## Возможности

- **Экран StandBy** (общий для всех режимов):
  - месяц-календарь с подсветкой сегодняшнего дня;
  - крупные часы + дата;
  - заряд батареи (опция);
  - карточка «сейчас играет» — появляется только когда реально играет музыка;
  - яркость текста, 12/24 ч, секунды — настройки.
- **Защита от выгорания пикселей (OLED)**: весь контент медленно «плавает» —
  сдвиг на несколько px каждую минуту, чтобы статичные пиксели не выгорали;
  фон всегда чистый чёрный (`#000000`).
- Три способа показа:
  1. **Кнопка «Показать сейчас»** — мгновенный полноэкранный предпросмотр
     (выход кнопкой «назад»), можно оставить как настольные часы.
  2. **Авто «при зарядке в горизонтали»** — наложение, которое само появляется,
     пока телефон заряжается лёжа горизонтально. Наложение **не блокирует
     касания** и само скрывается при отключении зарядки, повороте или из
     уведомления («Скрыть»). Это рабочий путь для OnePlus.
  3. **Системная заставка** — для прошивок, где Android сам запускает заставку
     при простое+зарядке.
- Без внешних библиотек (только Android SDK), интерфейс на русском (+EN).

## Как собрать и запустить

1. **Android Studio** → `File ▸ Open` → выбрать папку проекта (где
   `settings.gradle.kts`) → согласиться на Gradle Sync.
2. Студия сама скачает Gradle 8.6 и SDK (compileSdk 34; при необходимости
   поставьте Android 14 / API 34 через `SDK Manager`).
3. Подключите телефон (отладка по USB) или выберите эмулятор.
4. **Run ▶** (Shift+F10).

## Как пользоваться

1. Откройте приложение, нажмите **«Показать StandBy сейчас»** — посмотрите дизайн.
2. Включите **«Показывать при зарядке в горизонтали»** и выдайте разрешение
   «поверх других приложений» (и уведомления).
3. Положите телефон на подставку горизонтально и включите зарядку — появится
   StandBy-экран. Чтобы убрать: отключите зарядку, поверните вертикально или
   свайпните уведомление → «Скрыть».
4. Запустите музыку — внизу появится компактная карточка плеера.
5. (Опционально, для прошивок с заставкой) **«Также использовать как системную
   заставку»** и выберите «AlwaysON StandBy».

## Структура

```
app/src/main/
├─ AndroidManifest.xml
├─ java/com/aidarbreeze/alwayson/
│  ├─ MainActivity.kt            — настройки
│  ├─ StandbyActivity.kt         — предпросмотр (выход «назад»)
│  ├─ StandbyController.kt       — часы/дата/заряд/плеер + защита от выгорания
│  ├─ Prefs.kt
│  ├─ view/MonthCalendarView.kt  — рисованный месяц-календарь
│  ├─ media/MediaWatcher.kt      — чтение «сейчас играет»
│  ├─ service/OverlayService.kt  — авто «при зарядке в горизонтали»
│  └─ dream/ClockDreamService.kt — системная заставка
└─ res/
   ├─ layout/ standby_view.xml, activity_main.xml
   ├─ values(-ru)/ colors/strings/styles
   ├─ drawable/ (иконка, плеер-«таблетка»)
   └─ xml/dream_info.xml
```

## Минимальные требования / версии

- `minSdk 26` (Android 8.0+), `targetSdk/compileSdk 34` (Android 14).
- Kotlin 1.9.24, AGP 8.4.2, Gradle 8.6.
- Внешних библиотек нет.

> Если студия жалуется на `gradle-wrapper.jar` (бинарник не закоммичен): на машине
> с Gradle выполните `gradle wrapper --gradle-version 8.6`, либо укажите локальную
> дистрибуцию Gradle в `Settings ▸ Build Tools ▸ Gradle`.
