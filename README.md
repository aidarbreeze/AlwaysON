# AlwaysON

Android-приложение «всегда включённых часов», которое работает как замена/дополнение
стандартного *Always On Display*.

## ⚠️ Важно прочитать (что технически возможно)

На **не-rooted** Android не существует публичного API, чтобы рисовать настоящее
«always-on» изображение **при полностью выключенном экране** — для этого нужен
собственный AOD производителя (SystemUI), к которому сторонние приложения не
допускаются. Поэтому приложение даёт два максимально близких и **полностью
поддерживаемых системой** режима:

1. **Наложение (Overlay)** — большие приглушённые часы поверх текущего экрана
   («ночные» часы на подставке). Пока экран включён — поверх всего.
2. **Заставка (DreamService / Screen saver)** — часы, которые система сама
   включает, когда телефон простаивает и **заряжается/стоит в доке**.
   Это фактически и есть «always-on» на устройстве, т.е. на зарядке ночью.

---

## Возможности

- Большие цифровые часы, дата и заряд батареи.
- Регулировка яркости наложения (чтобы не слепило ночью).
- 12/24-часовой формат, секунды, процент заряда — переключатели.
- Выбор системой в качестве заставки (полуавтоматический всегда-включённый режим).
- Работает без интернета и без AndroidX — собирается «из коробки» в Android Studio.
- Интерфейс на русском (есть резерв на английском).

## Как собрать и запустить

1. **Android Studio** → `File ▸ Open` и выберите папку проекта (где лежит
   `settings.gradle.kts`). На вопрос про Gradle Sync — соглашайтесь.
2. Студия сама скачает Gradle 8.6 и SDK (compileSdk 34). При необходимости
   поставьте платформу Android 14 (API 34) через `SDK Manager`.
3. Подключите телефон по USB с включённой отладкой (`Developer options ▸ USB
   debugging`) или выберите эмулятор.
4. Нажмите **Run** ▶ (или Shift+F10) и выберите устройство.

## Как пользоваться

### 1. «Наложение» (ночные часы поверх экрана)

- Откройте приложение, включите переключатель **AlwaysON overlay**.
- При первом включении разрешите *«поверх других приложений»*.
- Часы появятся поверх текущего экрана. Скрыть — тем же переключателем или
  свайпнуть уведомление.
- Экран должен быть включён (это работает как настольные ночные часы).

### 2. Полуавтоматический always-on (заставка)

Это самый близкий к настоящему AOD режим — часы включаются сами, когда телефон
лежит и заряжается:

- Нажмите **«Открыть настройки заставки»** (или вручную: `Настройки ▸ Дисплей ▸
  Экранная заставка` / `Screen saver`).
- Включите заставку и выберите **«AlwaysON часы»**.
- Для условия запуска выберите **«В доке и при зарядке»** (или «Пока заряжается»).
- Когда поставите телефон на зарядку и он «уснёт», через несколько секунд
  появятся часы AlwaysON.

## Структура проекта

```
app/src/main/
├─ AndroidManifest.xml            — разрешения, activity, сервисы
├─ java/com/aidarbreeze/alwayson/
│  ├─ MainActivity.kt            — экран настроек
│  ├─ Prefs.kt                   — SharedPreferences-хранилище
│  ├─ AodViews.kt                — отрисовка времени/даты/батареи
│  ├─ NotificationHelper.kt      — постоянное уведомление сервиса
│  ├─ service/OverlayService.kt  — режим «наложение поверх экрана»
│  ├─ dream/ClockDreamService.kt — режим «заставка»
│  └─ recv/BootReceiver.kt       — автозапуск после перезагрузки
└─ res/
   ├─ layout/                    — aod_view.xml, activity_main.xml
   ├─ values / values-ru/        — строки (RU основной)
   ├─ mipmap-anydpi-v26/         — адаптивная иконка
   └─ xml/dream_info.xml         — метаданные заставки
```

## Минимальные требования / версии

- `minSdk 26` (Android 8.0+), `targetSdk/compileSdk 34` (Android 14).
- Kotlin 1.9.24, AGP 8.4.2, Gradle 8.6 (скачиваются автоматически).
- Внешних библиотек нет — используется только Android SDK.

## Если Android Studio ругается на Gradle wrapper

Бинарный `gradle/wrapper/gradle-wrapper.jar` не закоммичен (он не является текстом
и не мог быть создан в этой среде). Обычно это не мешает: студия сама читает версию
Gradle из `gradle/wrapper/gradle-wrapper.properties` и разворачивает её. Если всё же
появится ошибка вида `Could not find or load main class
org.gradle.wrapper.GradleWrapperMain`, сделайте один раз:

1. На машине, где есть Gradle: `gradle wrapper --gradle-version 8.6` в корне проекта
   (он создаст недостающий `gradle-wrapper.jar`), либо
2. В Android Studio: `File ▸ Settings ▸ Build, Execution, Deployment ▸ Build Tools ▸
   Gradle` → `Gradle user home` и разы «Use Gradle from: *Specified location*», указав
   каталог локальной Gradle-дистрибуции.

## Настройка имени/иконки (если нужно)

- Имя приложения — `values/strings.xml`, строка `app_name`.
- `applicationId`/пакет — `app/build.gradle.kts` и папка пакета в `java/`.
